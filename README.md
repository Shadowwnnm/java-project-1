# java-project-1

## About This Project
This repository contains three Java programs written to fulfil the COS 201 practical assignment. The programs cover simple calculations and basic data processing through user input.

## Included Programs

 File Name and Function 

`SimpleCalculator.java`: Accepts two numbers and carries out four basic mathematical operations. 
`AverageCalculator.java`: Takes three numbers as input and computes their mean. 
 `ItemCost.java`: Collects product details and calculates the total amount payable. 

## Prerequisites
Before running the programs, ensure you have installed:

- JDK version 8 or above.
- A Java editor such as VS Code, IntelliJ IDEA, or Eclipse.
- Access to a terminal or command prompt.

## Installation and Execution

**Step 1: Open the project folder**

Navigate to the directory containing the three `.java` files.

**Step 2: Build the programs**

Enter the following commands one after another:

```bash
javac SimpleCalculator.java
javac AverageCalculator.java
javac ItemCost.java
```

**Step 3: Start the applications**

Use the commands below to run each program:

```bash
java SimpleCalculator
java AverageCalculator
java ItemCost
```

## Learning Outcomes
The assignment helps demonstrate an understanding of Java fundamentals, including:

- Declaring variables and working with data types.
- Receiving input using the Scanner class.
- Performing mathematical operations.
- Using switch statements and conditional checks.
- Displaying calculated results to users.
